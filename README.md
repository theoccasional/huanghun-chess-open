Android 中国象棋客户端。自带引擎与开局库，可单机对弈、打谱、复盘与批量转换棋谱，
并支持「跨设备借引擎」——一台手机出借算力，另一台只负责界面与触摸。

本仓库是作者公开的 **GPL-3.0 源码**。公开版在原 2.9.316 基础上做了一轮“可公开分发”的整理：
随包棋谱只保留纯记录、现代棋书改为占位、分类内可上传、清数据不伤内置骨架、
三套自制背景音乐（AI 生成 + 轻度调整）、以及一轮墨玉·青瓷界面打磨。

当前版本：**2.9.317**（`versionCode 353`，公开版构建）

## 主要能力

- **对弈**：人机、双人、挑战残局；内置皮卡鱼（UCI）与多套开源引擎
- **棋谱 / 宝库**：PGN、中文记谱、ICCS、CBL、XQF、MXQ、UBB、FEN 等的导入导出与批转
- **复盘**：整局评估曲线、分档点评、错题本与 20 回合分页
- **开局库**：XQB / OBK / BOOK.DAT / PGN 等格式，可加载外部库
- **连线 / 观战**：识别屏幕与棋盘，整合 YK 连线内核（识别模型见「资源说明」）
- **跨设备借引擎**：发送端出借本机引擎，接收端只传着法，避免发热
- **棋例判定**：按亚象联《象棋比赛规例》处理长将、长捉、长打与重复局面

## 公开版改了什么

### 1. 随包棋谱：只留纯记录

| 分类 | 随包数量 | 内容 |
|---|---:|---|
| 五羊杯 | 29 | 第 1–29 届，纯着法 + 赛事 / 双方 / 结果 |
| 古谱 | 33 | 明清古谱原文，纯着法 |
| 名手对局 | 9 | 九位名手对局记录，纯着法 + 双方姓名 |

- 随包 CBL **已重写为纯着法记录**：开局旁白、局后总评、逐段注解、现代序跋与专辑解说全部剔除；
  只保留书名、双方、赛果、日期、着法与变招。
- 随包只含上述纯着法记录；现代专著、专辑、开局书、残局书、赛事集等类目为占位骨架，用户自行上传补充。
- 其余分类（习题 / 专著 / 专辑 / 其它 / 开局 / 残局 / 赛事）只保留**目录骨架**，
  书目标注「开发者未提供，请自行补充」，并在上传入口写明支持格式。

### 2. 分类内上传

- 第 1–11 个分类（十个内置分类 + 「我的上传」）各有自己的**上传入口**，
  导入的文件只归入该分类，不再一股脑堆到「我的上传」。
- 第 12 个起的分类（挑战棋谱 / 本地文档 / 我的对局等）**不设上传入口**，
  它们由挑战模式保存、本机文档扫描、续盘存档各自产生，避免来源混乱。
- 可导入格式：ZIP（内含 XQF / MXQ / CBL / CBR / PGN / TXT / UBB）、XQF、MXQ、
  CBL / CBR、PGN、中文记谱 TXT、东萍 UBB、FEN 题库。

### 3. 清数据不伤内置骨架

- 内置骨架在 APK 的 `assets/qipu_cbl/` 里，只读；系统「清除数据」不会删除它。
- 用户上传落 `filesDir/qipu_user/<分类>/`，清数据才会消失。
- 内置书只允许**显式删除**（弹窗提示“删除后无法恢复”）或按路径手动删除；
  删除 / 合成交互保留：删除在前、合成在后。

### 4. 音频

- 走子、碰撞、将军、吃子、悔棋、开始、结束等**短音效保持原样**。
- 三首背景乐为**自制音乐**（AI 生成 + 轻度调整，提示词仅基于风格 / 意象 / 情感需求，不含任何既有曲目名称），界面中性编号：

| 选项 | 文件 | 说明 |
|---|---:|---|
| 1MP3 | `snd/bgm1.mp3` | 自制背景乐（AI 生成 + 轻度调整） |
| 2MP3 | `snd/bgm2.mp3` | 自制背景乐（AI 生成 + 轻度调整） |
| 3MP3 | `snd/bgm3.mp3` | 自制背景乐（AI 生成 + 轻度调整） |

### 5. 界面

不改变「对弈 / 棋谱」两页结构与主要按钮位置，做一轮“墨玉 · 青瓷”视觉整理：

- 全局底色改为雾白/浅灰中性面，文字改墨色，界面 chrome 不再用奶油金；
- 青瓷绿作唯一主操作色，赤陶红只作危险/失败提示，暖木色只留给棋盘；
- 顶栏与常驻底栏改为白面 + 一道中性细线，靠投影与棋盘分层；
- 页签改为“青瓷绿 / 雾灰”两档，未选中用墨字，选中用白字；
- 按钮统一 10dp 圆角、medium 字重与克制的 ripple，去掉整颗胶囊与重渐变；
- 参数/视觉/更多三组底板改为同形白面细边，设置弹窗改为纯白纸面；
- 深色弹窗改用墨色底 + 低饱和暖铜强调，替代深胡桃 + 亮金；
- 清理按钮上混用的彩色 emoji，保留汉字标签与状态点。

## 资源说明

- 仓库包含引擎二进制与权重（`app/src/main/assets/engine/`、`app/src/main/jniLibs/`）、
  音效、棋谱与连线模型（`app/src/main/assets/link/`）。
- **识别模型 `app/src/main/assets/models/` 不随源码仓库分发**（已在 `.gitignore` 中排除）：
  `pose_model.onnx`（棋盘四角）、`layout_model.onnx`（整盘 90 格分类）、`yolo_model.onnx`（辅助检测）。
- 官方公开版 APK 由作者构建时放入上述三个自有模型，开箱即可用拍照摆子 / 识别；
  从源码自行构建时，如需同样能力，请把自有模型放入 `app/src/main/assets/models/` 后再构建。
  缺少模型时，对弈、棋谱、复盘不受影响，拍照识别会退回 OCR 或提示失败。

## 构建

环境（已验证）：

- **JDK 17**（17.0.2 可用；JDK 25 会因 AGP 解析失败）
- **Android SDK Platform 35**（`compileSdk 35`，`minSdk 24`，`targetSdk 28`）
- **Gradle 8.5**（AGP 8.2.0；仓库不带 wrapper，使用系统 Gradle 即可）
- 预编译 `.so` 已随仓库提供，常规构建**不需要** NDK

1. 在工程根目录创建 `local.properties`：

```properties
sdk.dir=/path/to/Android/Sdk
```

2. 构建全量包：

```bash
gradle :app:assembleFullRelease
```

产物：`app/build/outputs/apk/full/release/app-full-release.apk`
（无签名文件时产物名为 `app-full-release-unsigned.apk`）

### 签名（可选）

仓库**不含**签名文件。把自有 keystore 放到工程根目录并命名 `pikafish-release.jks`
即可自动签名；也可用环境变量覆盖口令：

```bash
export HHXQ_STORE_PASSWORD=你的口令
export HHXQ_KEY_PASSWORD=你的口令
export HHXQ_KEY_ALIAS=你的别名
```

没有 keystore 时只产出未签名包，构建不会因此失败。公开分发请使用自己的密钥，
不要复用原作者签名（否则会被视为同一发布者的升级包）。

## 已知限制

- 仅 `arm64-v8a`；Android 7.0（API 24）及以上。
- 无在线对战、无账号、无社交；跨设备借引擎需两台设备同一局域网 / 可互通。
- 识别模型不随源码仓库提供，源码构建默认没有拍照识别。
- 随包棋谱只到 2020 年代前的公开记录；现代棋书请自行上传并确保你有相应授权。
- `targetSdk 28` 为兼容旧设备保留，新系统上可能有存储 / 权限提示差异。
