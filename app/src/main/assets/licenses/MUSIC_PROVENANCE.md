# 背景音乐生成记录（MUSIC_PROVENANCE）

三首背景乐均为本工程自制：由 AI 音乐生成服务（秒哒平台 / MiniMax 音乐生成模型）
依据**仅描述风格、意象与情感需求**的提示词生成，随后进行轻度人工调整
（音量平衡、淡入淡出、节选）。

## 生成方针

- 提示词只写风格 / 意象 / 情感（如：黄昏、棋盘、苍凉、慢板、呼吸停顿等），
  **未引用任何既有歌曲名称、歌词或旋律片段**；
- 生成后人工轻度调整（音量、淡入淡出、节选），未混入任何第三方采样；
- 生成与调整记录以各文件 AIGC 元数据（ProduceID）与创建时间为准。

## 隐式标识

三首 MP3 均保留平台 **AIGC 隐式标识**元数据（`ContentProducer=MiniMax`、
唯一 `ProduceID`、TC260 签名），可用 `ffprobe` 校验；转码/再处理不得使用
会抹除该标识的工具。这一元数据即生成来源的硬证据，无需其他账号即可核验。
